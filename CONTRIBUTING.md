# Contributing Guidelines

Thank you for your interest in contributing to the **OWASP Top 10 Neocloud and AI Data Center Security Risks** (FORGE)! We are a community-driven, vendor-neutral project and welcome all contributors, regardless of their background or experience level.

## Community-Driven Project

FORGE is an open source effort that thrives on community collaboration. We welcome ideas, contributions, suggestions, and remarks from security professionals, researchers, cloud and HPC operators, data center engineers, and anyone passionate about AI infrastructure security. You do not need to be an expert — fixing a link, sharpening a mitigation, or adding a reference all help.

## How to Contribute

- **Open an issue** to report an error, suggest an improvement, or propose new content.
- **Open a pull request** for changes. Small fixes can go straight to a PR; for larger changes, open an issue first so we can agree on direction.

Please keep contributions **vendor-neutral** (describe controls and security properties, not products), **evidence-based** (cite CVEs, standards, vendor documentation, or research), and in scope: AI infrastructure and the data centers that house it, not model- or application-layer risks.

## Join Our Community

- Chat with us on [OWASP Slack](https://owasp.org/slack/invite) in [`#project-neocloud-ai-infrastructure`](https://owasp.slack.com/archives/C0C7MBFJLD6)
- Contributions are licensed under [CC BY-NC-SA 4.0](LICENSE) and credited in each release
- No OWASP membership required to contribute!

## Code of Conduct

We are committed to a welcoming, harassment-free experience for everyone. Be respectful of differing viewpoints, accept constructive criticism gracefully, and focus on what is best for the community. All participation follows the [OWASP Code of Conduct](https://owasp.org/policy/code-of-conduct); concerns can be reported to the project leaders or to [owasp.foundation@owasp.org](mailto:owasp.foundation@owasp.org).

For the project overview and leaders, see the [official OWASP project page](https://owasp.org/projects/top-10-ai-infrastructure-security-risks).
